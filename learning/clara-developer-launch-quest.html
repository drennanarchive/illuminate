Five words worth recognizing

Repository
A project folder with tracked history.
Clone
A connected copy of a GitHub repository on your computer.
Branch
A safe alternate path for an experiment.
Commit
A named checkpoint you can return to.
Diff
The exact before-and-after view of changed lines.
